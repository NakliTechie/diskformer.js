diskformer · an embedding table on disk

A 128 MB embedding table (131,072 tokens × 256 floats) lives in this browser's private storage (OPFS). The GPU holds only 1,024 rows (1 MB). For 200 steps of 32 token ids, the page asks the cache for the rows, runs a WGSL kernel that gathers them through the returned slots, reads the result back, and checks every value against the source table. Needs Chrome or Edge with WebGPU.
